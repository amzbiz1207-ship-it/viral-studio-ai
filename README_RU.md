# Viral Studio AI — v2.0 (двуязычный рабочий прототип)

**Не связан с Virales.io или ChatPlace Virale.** Использует самостоятельную структуру, дизайн и код. Скриншоты сторонних сайтов использованы только как вдохновение для сценариев использования.

## Что добавлено во второй версии

- Новая главная страница **AI-студия и шаблоны**: одно поле для описания идеи, выбор подходящего инструмента.
- Каталог из **24 инструментов** по категориям: **Видео, Карусели, Тренды, Контент, Изображения, Чат-боты**.
- Кнопка **«Создать бесплатный черновик»**: работает без ключей, по локальным шаблонам; не выдаётся за AI.
- Кнопка **«Создать с Gemini»**: полноценная генерация текста, если настроен Gemini API key.
- Возможность сохранить результат в библиотеку и скачать Markdown.
- Двуязычный интерфейс RU / EN, собственное тёмное оформление.
- Сохранены функции v1: анкета автора, несколько проектов, семидневный календарь, пять хуков, покадровый сценарист, поиск реальных видео по YouTube API, разбор ссылок по доступным метаданным, ручная аналитика и резервное копирование JSON.
- **`demo.html`** — отдельная офлайн-демонстрация кабинета. Откройте двойным щелчком в браузере; установка Python не нужна. Демонстрация не связана с платными API и не собирает реальные тренды.

## Как попробовать без установки

1. Распакуйте ZIP.
2. Найдите **`demo.html`** внутри папки.
3. Дважды щёлкните по файлу: он откроется в браузере. Выбирайте разделы и карточки, вводите собственную идею, создавайте пример черновика.
4. Это предварительный интерфейс, а не опубликованный сайт. Данные demo.html сохраняются только локально в браузере.

## Как запустить полноценный Python-прототип

С компьютера с Python 3.11+:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откроется локальный адрес `http://localhost:8501`.

## Как разместить на GitHub и Streamlit Community Cloud

1. Создайте **новый**, отдельный репозиторий `viral-studio-ai` (существующий сайт не затрагивать).
2. Загрузите в корень репозитория файлы **`app.py`, `core.py`, `services.py`, `studio_tools.py`, `requirements.txt`**. Также можно загрузить `README_RU.md` и `.streamlit/config.toml`.
3. Перейдите на https://share.streamlit.io/ и разверните новый сайт, выбрав репозиторий, ветку `main`, основной файл `app.py`.
4. В разделе **Settings → Secrets** приложения добавьте собственные ключи, **не в открытый GitHub**:

```toml
GEMINI_API_KEY = "ВАШ_КЛЮЧ"
YOUTUBE_API_KEY = "ВАШ_КЛЮЧ"
GEMINI_MODEL = "gemini-2.5-flash"
```

AI-генерация требует доступа к выбранной модели. Если модель недоступна, смените её на действующую в Google AI Studio. YouTube API — официальное публичное API с квотой.

Ключ Gemini: https://aistudio.google.com/apikey

YouTube API v3: https://console.cloud.google.com/apis/library/youtube.googleapis.com

## Что делает каждый модуль

- **Видео**: сценарии, промпты для Flow/Kling, монтажные планы (не готовые видео).
- **Карусели**: тексты 8 слайдов и промпты (не готовые изображения).
- **Тренды**: реальный поиск в YouTube, только при наличии API ключа; не Instagram/TikTok.
- **Контент**: тексты, хуки, контент-план, аудит по предоставленной информации.
- **Изображения**: английские промпты для внешних генераторов, а не рендер изображения.
- **Чат-боты**: схемы диалогов и воронок, не развернутые боты.

## Ограничения (обязательно прочитайте)

- Это **прототип**, а не коммерческий SaaS. Реальной регистрации, платёжной системы, постоянной базы, Telegram-бота, командных приглашений и ролей с доступами пока нет.
- Генерация **MP4 и изображений не встроена**. Сервисы Google Flow, Kling и др. не подключены.
- Нет доступа к закрытой аналитике Instagram / TikTok или к контенту, который пользователь не предоставил.
- Проекты в основной версии хранятся в Streamlit session_state и могут потеряться после перезапуска. Для сохранения выберите **Настройки → Скачать все данные JSON**. Демо HTML хранит избранное только в конкретном браузере.
- Не вводите пароли от соцсетей, платёжные данные и конфиденциальную клиентскую информацию в этот демонстрационный сайт.
- `views/day` — приближённое среднее с даты публикации, а не измерение просмотров за последние сутки; трендовость без сравнения с историей канала не доказана.
- При публичном развертывании нельзя использовать прототип как многопользовательский сервис без защищённой авторизации и разделения пользовательских данных.
